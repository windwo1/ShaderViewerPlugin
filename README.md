# Shader Viewer Plugin
A fork of the MeshSetPlugin plugin for Frosty Editor, allows for viewing ShaderGraph assets in the mesh viewer. Also includes real time parameter editing, minimal VisualEnvionment viewing, custom skyboxes and variation viewing (was already a thing, but was useless with the original fallback shader).

This plugin is very unfinished, don't expect shaders to be 100% accurate, or for this work well with other games (mostly only tested with GW2). A shader cache will need to be generated once for each game.

Shader Data reading by Brawletendo, with a few tweaks: https://github.com/Brawltendo/FrostyShaderDataPlugin
